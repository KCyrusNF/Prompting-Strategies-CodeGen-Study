Here's a Python function sum_digits(n) that calculates and returns the sum of all digits in the integer n:

def sum_digits(n):
    # Convert the number to a string to easily iterate over each digit
    return sum(int(digit) for digit in str(abs(n)))

# Example usage:
n = 12345
print(sum_digits(n))  # Output: 15
Explanation:


abs(n) ensures the function works for negative numbers as well by removing the sign.


str(abs(n)) converts the number to a string so we can iterate through each character (digit).


int(digit) converts each character back to an integer for the summing process.


sum() is used to calculate the total sum of these digits.

Here's the Python function to convert Fahrenheit to Celsius:
def to_celsius(f):
    return (f - 32) * 5 / 9
You can use this function by passing the Fahrenheit temperature as an argument, and it will return the equivalent temperature in Celsius.

For example:
print(to_celsius(32))  # 0.0
print(to_celsius(100))  # 37.777...

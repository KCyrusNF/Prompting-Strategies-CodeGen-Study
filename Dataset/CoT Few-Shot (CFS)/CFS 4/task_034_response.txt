Steps:

Convert the number to a string: This allows us to treat the number as a sequence of characters, which we can easily iterate over.

Iterate over each character: We can loop through each character (which represents a digit) in the string.

Convert each character back to an integer: After extracting each digit as a string, we need to convert it to an integer to perform the addition.

Sum the digits: Keep a running total by adding each integer to an accumulator variable.

Return the sum: Finally, return the total sum of the digits.

Function implementation:
def sum_digits(n):
    # Step 1: Convert the number to a string
    n_str = str(n)
    
    # Step 2: Initialize a variable to store the sum of digits
    total = 0
    
    # Step 3: Iterate through each character in the string
    for char in n_str:
        # Step 4: Convert each character back to an integer and add it to the total
        total += int(char)
    
    # Step 5: Return the total sum of digits
    return total

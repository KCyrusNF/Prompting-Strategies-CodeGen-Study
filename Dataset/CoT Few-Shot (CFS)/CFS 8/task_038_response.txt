Steps:


Initialize the result variable: We initialize a variable called result to 1. This is because multiplying by 1 does not change the value of any number.


Loop through integers from 1 to n: We will loop through each integer from 1 to n (inclusive). In each iteration of the loop, we will multiply the current value of result by the loop index i.


Return the result: After the loop finishes, the value of result will be the factorial of n, and we return it.


Python Code:
def factorial_iter(n):
    result = 1  # Start with 1 since multiplying by 1 doesn't change the value
    for i in range(1, n + 1):  # Loop from 1 to n (inclusive)
        result *= i  # Multiply result by i in each iteration
    return result

To solve the leap year problem, we can follow the conditions you've outlined:

If the year is divisible by 400, it is a leap year.

If the year is not divisible by 400, check if it is divisible by 100. If it is, it is not a leap year.

If the year is not divisible by 100, check if it is divisible by 4. If it is, it is a leap year.

If none of the above conditions are met, it is not a leap year.

Here is the Python function that implements this:

def is_leap_year(year):
    # Check if divisible by 400
    if year % 400 == 0:
        return True
    # Check if divisible by 100 but not 400
    elif year % 100 == 0:
        return False
    # Check if divisible by 4 but not 100
    elif year % 4 == 0:
        return True
    # If none of the above conditions are met, it's not a leap year
    else:
        return False

Explanation:

The first if checks if the year is divisible by 400. If true, it's a leap year.

The elif checks if the year is divisible by 100 but not by 400. In this case, it's not a leap year.

The next elif checks if the year is divisible by 4 but not by 100. If true, it's a leap year.

If none of these conditions are met, the function returns False, indicating it's not a leap year.

def average_of_list(nums):
    total = 0
    for value in nums:
        total += value
    length = 0
    for _ in nums:
        length += 1
    return total / length
Explanation:

The first loop calculates the sum manually (stored in total).

The second loop counts how many items are in the list (stored in length).

Then we return total / length, which is the arithmetic mean.

Here’s the step-by-step and the function you asked for.

Subtract 32 from the Fahrenheit temperature.

Multiply that result by 5/9.

Return the Celsius value.

def to_celsius(f):
    """Convert Fahrenheit to Celsius."""
    return (f - 32) * 5/9


Quick checks:

print(to_celsius(32))   # 0.0
print(to_celsius(212))  # 100.0

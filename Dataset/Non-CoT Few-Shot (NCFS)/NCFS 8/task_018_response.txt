def factorial_iter(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
✅ Explanation:

We start with result = 1 because factorial multiplies numbers, and multiplying by 1 keeps the result unchanged.

Then we loop from 1 up to n, multiplying each number into result.

Finally, the function returns the factorial value.

Example runs:
print(factorial_iter(0))  # 1
print(factorial_iter(1))  # 1
print(factorial_iter(4))  # 24

def sum_digits(n):
    # Convert the number to a string to iterate over its digits
    return sum(int(digit) for digit in str(n))

# Test cases
print(sum_digits(123))  # Output: 6
print(sum_digits(405))  # Output: 9
print(sum_digits(0))    # Output: 0
Explanation:

The function sum_digits(n) first converts the number n to a string using str(n).

It then iterates over each character (digit) in the string, converts each character back to an integer, and sums them up using the sum() function.

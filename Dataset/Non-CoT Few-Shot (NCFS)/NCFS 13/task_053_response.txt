To create a function that extracts only the even numbers from a list, you can use a list comprehension. Here's how you can write the filter_even function:
def filter_even(nums):
    return [num for num in nums if num % 2 == 0]
Explanation:

The list comprehension iterates over each element in the nums list.

The if num % 2 == 0 condition filters out only the even numbers.

The result is returned as a new list containing only the even numbers.

Example Usage:
print(filter_even([1, 2, 3, 4, 5, 6]))  # Output: [2, 4, 6]
print(filter_even([1, 3, 5]))           # Output: []
print(filter_even([2, 4, 8]))           # Output: [2, 4, 8]
print(filter_even([10, 15, 20, 25]))    # Output: [10, 20]

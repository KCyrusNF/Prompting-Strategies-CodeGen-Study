Sure! Here's the function count_positives(nums) that will count how many numbers in the list are strictly greater than 0:
def count_positives(nums):
    # Initialize the counter to 0
    counter = 0
    
    # Loop through each number in the list
    for num in nums:
        # If the number is greater than 0, increment the counter
        if num > 0:
            counter += 1
    
    # Return the total count of positive numbers
    return counter
How it works:

The function initializes a counter at 0.

It loops through each number in the list nums.

If the number is greater than 0, it increases the counter by 1.

Finally, the function returns the count of positive numbers.
Example usage:
nums = [1, -3, 4, 0, -2, 5]
result = count_positives(nums)
print(result)  # Output will be 3, as there are three positive numbers: 1, 4, and 5

Step 1. Subtract the two numbers
Compute the difference:

diff = a - b

This tells us how far apart they are, but it might be negative.

Step 2. Check if the difference is negative
If diff < 0, that means the result is negative.

Step 3. Flip the sign if it's negative
To flip the sign, we can multiply by -1 (or just take the opposite).
So:

if diff < 0, set diff = -diff

Now diff is guaranteed to be non-negative.

Step 4. Return that value
The value we have in diff is now the absolute difference |a - b|.

Putting it all together in code:
def absolute_difference(a, b):
    diff = a - b
    if diff < 0:
        diff = -diff
    return diff
This function returns the absolute difference between a and b.

Let's break this down step by step to write the is_leap_year function:

Steps to check if a year is a leap year:

Divisible by 4: A year must be divisible by 4 to be considered a leap year.

Not divisible by 100, unless divisible by 400: If a year is divisible by 100, it must also be divisible by 400 to be a leap year.

Now let's translate this into a Python function:
def is_leap_year(year):
    # Step 1: Check if divisible by 4
    if year % 4 == 0:
        # Step 2: Check if divisible by 100
        if year % 100 == 0:
            # Step 3: Check if divisible by 400
            if year % 400 == 0:
                return True  # It is a leap year
            else:
                return False  # It is not a leap year
        else:
            return True  # It is a leap year
    else:
        return False  # It is not a leap year
How it works:

The first condition checks if the year is divisible by 4.

If it is divisible by 4, then we check if it is also divisible by 100.

If divisible by 100, we check if it's divisible by 400 to decide if it is still a leap year.

If any of these conditions fail, the year is not a leap year.

Example runs:
print(is_leap_year(2020))  # True, divisible by 4, not by 100
print(is_leap_year(1900))  # False, divisible by 100 but not by 400
print(is_leap_year(2000))  # True, divisible by 400
print(is_leap_year(2023))  # False, not divisible by 4
